# PocketSmart AI: Smart Budget & Recommendation Assistant

PocketSmart AI is a GenAI-powered recommendation system that delivers personalized, budget-based suggestions for products and services across three planners: Home Interior, Party Planning, and Jewelry.

## ✨ Features
- **Home Interior Budget Planner:** Suggests furniture, lighting, and decor within budget.
- **Party Budget Planner:** Allocates budget across catering, decoration, and entertainment.
- **Jewelry Budget Planner:** Recommends jewelry matching your outfit (image upload supported).
- **Smart Shopping Links:** Auto-generates search links for Amazon, Flipkart, IKEA, Swiggy, Zomato, and more.
- **AI-Powered:** Uses Google Gemini 3.8 Flash for generating structured recommendations.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python
- **Frontend:** HTML, CSS, Jinja2
- **AI:** Google Gemini (`gemini-3.8-flash`) via `google-genai` SDK
- **Image Processing:** Pillow
